
This repository documents my hands-on learning and implementation of Core Java concepts through practical exercises and a Bank Application project. 
It covers object-oriented programming fundamentals including classes, objects, constructors, inheritance, interfaces, abstract classes, encapsulation, and polymorphism. 
The repository also includes extensive practice on String, StringBuilder, and StringBuffer methods with real-world examples, along with exception handling implementations.

As part of the learning process, 

I designed and continuously improved a console-based Bank Application featuring account creation, deposits, withdrawals, and partial implementation of fund transfer functionality. 
The project was manually tested and refined through iterative development, bug fixing, and code restructuring to improve understanding of Java architecture and best practices.

Additionally, this repository contains structured daily practice tasks, to-do exercises, and incremental improvements demonstrating consistent progress in problem-solving,
 debugging, and application development using Java.
